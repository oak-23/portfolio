# Personal portfolio website

Built using React + TypeScript + Vite.

CV-backed content lives in the education, experience, selected work, skills, languages, accolades, competition, and contact components under `src/components/`.

Keep selected-work descriptions in `Projects.tsx` and project-to-skill hover associations in `ExperienceMap.tsx` aligned with the corresponding CV entries.

Preserve the existing self-introductions in `Hero.tsx` and `Footer.tsx` when updating CV-backed content.
